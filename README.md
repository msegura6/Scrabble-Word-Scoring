Scrabble Word Scoring

Overview: This project implements a program in C that calculates and compares Scrabble-style word scores for two players based on standard letter point values.

The project was completed as part of Harvard University's CS50: Introduction to Computer Science course on edX.

Problem Description: Given two user-provided words, the program computes the total score for each word by summing the point values of its letters and determines the winner.

The solution processes each character in the input words, applies consistent scoring rules, and ignores non-alphabetic characters.

Methods:
-Array-based mapping of letters to point values
-String processing and character normalization
-Input validation and preprocessing
-Iterative and conditional logic for score calculation and comparison

Tools:
-C
-Standard C libraries 

How to Run:
-Compile the program using a C compiler
-Run the program and enter words for two players when prompted
